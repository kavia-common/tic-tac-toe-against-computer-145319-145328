# Tic‑Tac‑Toe Frontend (React • Ocean Professional)

A lightweight React app where the user (X) plays Tic‑Tac‑Toe against the computer (O) using a modern, minimalist style with blue and amber accents.

## Features
- Interactive 3x3 board with hover/press states
- Status message (whose turn, win/lose/draw)
- Restart game button
- Highlighted winning line
- Responsive and accessible

## Scripts
- npm start
- npm test
- npm run build

## Styling
The Ocean Professional theme is applied via CSS variables and component classes in `src/App.css`:
- Primary: #2563EB
- Secondary/Success: #F59E0B
- Error: #EF4444
- Background: #f9fafb, Surface: #ffffff, Text: #111827

## Structure
- src/App.js: Game logic, AI, and UI
- src/App.css: Styles and layout
- src/index.js, src/index.css: App bootstrap/minimal resets

No environment variables or external services are required.
